# BudgetLens AI 入門

這份文件帶你從第一次接觸專案開始，了解它能做什麼、如何在自己的電腦啟動，以及怎麼上傳預算資料和試算年度預算。若你只想先看到結果，從「快速啟動」開始即可。

## 這個專案在做什麼？

BudgetLens AI 是一個預算分析後端原型。你提供 CSV 檔案後，它會依部門彙整預算和實際支出，估算年底支出及超過年度預算的可能性。你也可以暫時調整某部門年度預算，查看預測如何改變；這就是 What-If（假設情境）試算。

目前專案有資料清理、分析計算和 API（讓其他程式呼叫的介面），但正式互動儀表板尚未整合。現在可以先用瀏覽器裡的 Swagger 操作頁試用 API。

## 快速啟動

以下指令請在 Windows PowerShell 的專案根目錄執行，也就是看得到 `pyproject.toml` 和 `src` 資料夾的位置。

### 1. 安裝專案

若使用專案內現成的 Python 3.14 虛擬環境：

```powershell
.\.venv-py314\Scripts\python.exe -m pip install -e .
```

若你沒有這個虛擬環境，可以自行建立並安裝：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

虛擬環境是專案專用的 Python 執行空間；安裝套件時使用它，可以避免影響電腦上其他 Python 專案。

### 2. 啟動 API

使用現成虛擬環境時：

```powershell
.\.venv-py314\Scripts\python.exe -m uvicorn budgetlens.api:app --reload
```

若剛才建立並啟用了 `.venv`，則執行：

```powershell
python -m uvicorn budgetlens.api:app --reload
```

看到 Uvicorn 顯示服務正在 `http://127.0.0.1:8000` 執行後，保持這個 PowerShell 視窗開啟。`--reload` 會在程式碼變更時自動重啟服務。

### 3. 開啟操作頁

在瀏覽器前往 <http://127.0.0.1:8000/> 開啟 BudgetLens 預算儀表板，直接上傳 CSV 查看各部門支出、年底預測和 What-If 試算。FastAPI 的 Swagger 操作頁仍可在 <http://127.0.0.1:8000/docs> 使用。若要停止服務，回到 PowerShell 按 `Ctrl+C`。

## 準備預算 CSV

CSV 是一種表格文字檔，可以用 Excel 編輯後另存為 CSV。每一列代表一個部門、月份和費用類別的月預算與實際支出。檔案使用 UTF-8 編碼，所有金額要使用同一幣別。

| 欄位 | 必填 | 範例 | 意思 |
|---|---|---|---|
| `department` | 是 | `研發部` | 部門名稱，不能空白 |
| `period` | 是 | `2026-08` | 月份，格式必須為 `YYYY-MM` |
| `budget` | 是 | `50000` | 該月該類別的預算，不能是年度預算重複值 |
| `actual` | 是 | `53000` | 該月該類別的實際支出；未發生／未回報的未來月份可留白，同一部門月份的所有類別都須留白 |
| `category` | 否 | `雲端服務` | 費用類別；不提供時會自動填入 `Uncategorized` |

例如：

```csv
department,period,category,budget,actual
研發部,2026-07,雲端服務,50000,48000
研發部,2026-08,雲端服務,50000,53000
行銷部,2026-08,廣告投放,80000,72000
```

`budget` 必須是非負數；已發生月份的 `actual` 也須為非負數。未來留白的 `actual` 代表未知，不代表 0，而且留白月份須連續位於該部門資料尾端。零預算可以輸入，但以零作分母的使用率或差異百分比會顯示為 `null`（沒有可計算的數值）。專案範例檔在根目錄的 `sample_budget.csv`；`sample_budget_forecast_to_oct.csv` 則可用來試算 1–10 月實支及 11–12 月預算。

## 在 Swagger 裡分析 CSV

1. 在 `/docs` 找到 `POST /api/v1/analyze`，按 **Try it out**。
2. 在 `file` 欄位選擇 CSV 檔。`currency` 是選填欄位，預設為 `TWD`；如果金額不是新台幣，請填入正確幣別代碼。
3. 按 **Execute**。成功時，回應會列出各部門分析，並提供 `analysis_id`（這次分析的識別碼）。請先留著這個 ID，後續試算會用到。

你也可以先呼叫 `GET /api/v1/health`。若回傳 `{"status":"ok"}`，代表 API 正在服務。

## 讀懂分析結果

每個部門會有以下常用資料：

- `budget`、`actual`：最新年度中已提供月份的預算與實際支出加總。
- `variance`：實際支出減預算；正數代表超出已提供月份的預算，負數代表低於預算。
- `usage_rate`：實際支出除以預算。API 傳回小數，例如 `0.8` 是 80%。
- `annual_budget`：預測使用的年度預算基準。預設用平均月預算乘 12；做 What-If 時可用你輸入的年度預算取代。
- `forecast.year_end_amount`：模型估算的年底總支出。
- `forecast.ci95`：模型估計的 95% 區間，包含 `lower`（下限）和 `upper`（上限）；月份少於兩個時為 `null`。
- `forecast.overrun_probability`：依目前 run-rate（支出速度）估算超過年度預算的機率。這是簡化模型估計，不是保證。
- `forecast.bayesian_overrun_probability`：依歷史速率、支出進度和季節因素分類所算的貝氏網路機率。它和前一項使用不同方法，不能當成同一種機率。
- `status`：目前暫定的燈號。機率低於 33% 為綠燈，33% 到未滿 67% 為黃燈，67% 以上為紅燈；若 run-rate 機率無法估算，燈號改參考貝氏機率。
- `monthly`：該部門最新年度各月份的預算、實際支出和使用率。

若資料從 1 月開始連續到最新月份，預測會以年初至今支出加上剩餘月份的平均支出估算年底金額。若月份不完整，則用已提供月份的平均支出乘以 12 年化；`forecast.method` 會指出採用哪種方式。單一月份不足以估計支出波動，因此區間和 run-rate 超支機率會是 `null`。

## 試算另一個年度預算

分析成功後，在 Swagger 找到 `POST /api/v1/simulate`，按 **Try it out**，把下列內容貼到請求欄位。請將 ID 換成你剛才收到的 `analysis_id`，並把部門名稱改成 CSV 裡實際存在的名稱：

```json
{
  "analysis_id": "貼上你的分析識別碼",
  "overrides": [
    {"department": "研發部", "annual_budget": 1500000}
  ]
}
```

按 **Execute** 後，回應仍會列出部門分析。比較新的 `annual_budget`、`forecast.year_end_amount`、`forecast.overrun_probability` 和 `status`，即可觀察假設預算調整後的變化。這不會改動原始 CSV。分析快照目前保存在 API 程序記憶體中；服務重啟後，請重新上傳 CSV 並取得新的 `analysis_id`。

## 目前做到哪裡

**已有初版：** CSV 欄位清理和檢查、部門預算與實際支出彙整、年底 run-rate 預測及區間、貝氏網路超支風險估計、FastAPI 分析端點和年度預算 What-If 試算。`sample_budget.csv` 已用於分析與試算示範。

**還在待辦：** 預算不足和執行落後警示、Z-score 異常診斷、部門層級的主因與自然語言說明，以及更多年中資料情境驗證。現有儀表板提供 CSV 分析、部門概覽、月度圖表和單一部門年度預算情境試算。

## 解讀結果時要記得

- 預測使用簡化的支出速度和 Student-t 波動估算，尚未經時間序列回測驗證。資料月份少時，結果的不確定性可能很大。
- 貝氏網路的先驗與條件機率是暫定的專家假設，不是從企業歷史資料訓練或校準所得。
- 範例 CSV 覆蓋完整 1 至 12 月，適合試操作；不適合用來證明年中預測已經驗證。
- `diagnostics` 目前固定是空陣列；警示規則雖有草稿，尚未接入 API。不要把目前結果解讀成已完成的異常診斷或管理建議。
